How it works

  1. Get test tokens. Connect MetaMask on Sepolia and take 100 free MATCH from the faucet once a day. You also need a little Sepolia ETH for gas, available from a public faucet.
  2. Pick a side. Tap a team's half of the rink and choose your stake. All stakes on a game form one pool; the payout shown is what you would get if the game ended with the pool as it is now.
  3. Collect. When the game is final, 2 % of the pool is burned and the rest is split between everyone who backed the winner, in proportion to their stake. Postponed games refund everyone in full.

What you are trusting

Results are written on-chain by one oracle account that runs every 30 minutes on GitHub Actions. It can only open, settle and cancel games; it cannot touch anyone's tokens. Every decision it makes is logged with the raw source data in a public audit log. If it ever goes silent, anyone can cancel a game three days after face-off and everyone gets their stake back.

Educational project on a test network. MATCH has no monetary value and cannot be bought or sold. Match data: TheSportsDB. Source code on GitHub.
